# Affilix — Selling Point Framework

## Purpose

Convert verified product information into usable UGC selling points without inventing claims.

## Selling Point Structure

Each selling point should contain:

### Feature
What the product has.

### Functional Benefit
What that feature helps the user do.

### User Value
Why that benefit matters to the target audience.

### Evidence
What supports the statement.

### Confidence
- Verified
- User-provided
- Reference-supported
- Unknown

## Example Structure

Feature:
[FACT]

Functional Benefit:
[SUPPORTED BENEFIT]

User Value:
[RELEVANT AUDIENCE VALUE]

Evidence:
[SOURCE]

## Prioritization

Selling points should be selected based on:

1. Campaign objective
2. Audience relevance
3. Product differentiation
4. Demonstrability in UGC
5. Evidence strength
6. Platform suitability

This is prioritization for content construction, not a claim that one product attribute is objectively superior.

## Rule

Do not convert an unsupported feature into a performance promise.
