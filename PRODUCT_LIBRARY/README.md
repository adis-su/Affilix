# Affilix — Product Library

## Purpose

The Product Library is the source of truth for product information used by the UGC Affiliate Engine.

It separates factual product data from creative interpretation.

## Product Flow

Product Input
→ Product Identity
→ Features
→ Benefits
→ Selling Points
→ Evidence
→ Claims Validation
→ Content Angles
→ UGC Production

## Core Rule

Never invent product specifications, performance claims, pricing, discounts, availability, reviews, certifications, or guarantees.

If information is missing, mark it as unknown or request the minimum required information.

## Product Records

Each product should have a structured product record following product_schema.md.

## Separation of Facts and Creative

### Product Facts

What the product is and what is actually supported by references or supplied information.

### Creative Interpretation

How those facts can be turned into:

- Hooks
- Angles
- Storylines
- Demonstrations
- Benefits
- Objection handling
- CTAs

Creative interpretation must not become a new product claim.
