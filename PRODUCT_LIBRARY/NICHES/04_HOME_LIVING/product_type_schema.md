# Home & Living — Product Type Schema

Status: ACTIVE

## Purpose

Defines runtime product-type categories for Home & Living without creating separate creative engines.

## Product Types

- kitchen
- organization
- cleaning
- decor

All listed product types currently have ACTIVE detailed rules.

## Runtime Principle

Universal rules + Home & Living niche rules + selected product-type rules are loaded into the existing Affilix engines.

Product-type rules must not override the source-of-truth hierarchy.

## Minimum Product-Type Context

Each product should preserve, when supplied:

- product identity
- form and dimensions/proportions
- material/finish
- color
- branding/label
- configuration
- intended use
- supplied environment/context
- supplied functional claims

Do not invent dimensions, materials, capacity, durability, performance, safety certifications, or personal experience.
