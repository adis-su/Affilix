# Bodycare Product Type

Status: ACTIVE

## UGC Patterns
- routine
- application demonstration
- texture/product showcase
- unboxing
- lifestyle
- supported problem-solution

## Interaction
Application must be physically plausible for the supplied product form. Do not invent application areas, dosage, frequency, or bodily effects.

## Visual Lock
Preserve packaging, product form, label, branding, color, and supplied texture references.

## Claims
Do not invent medical outcomes, treatment/cure claims, guaranteed results, clinical claims, percentage improvements, certifications, or expert endorsements.

## QC
Check product identity, application plausibility, creator identity, framing, and every product claim.
