# Beauty Niche

Status: ACTIVE

## Product Types
- skincare
- makeup
- haircare
- bodycare

## Common UGC Patterns
- routine
- application demonstration
- texture showcase
- product showcase
- unboxing
- supported problem-solution
- lifestyle

## Visual Considerations
Prioritize exact packaging, label/branding consistency, supported product appearance, realistic application, clean interaction, creator identity, and natural skin/hair representation.

## Interaction Considerations
Application actions must be physically plausible and consistent with the supplied product form.

## Claim Context
Never invent medical outcomes, treatment/cure claims, guaranteed results, percentage improvement, clinical/testing claims, certifications, expert endorsements, before/after results, or personal experience. Use such claims only when explicitly supported by source material.

## QC
Check packaging, label, application method, supplied quantity/placement requirements, creator identity, and every product claim.
