# Skincare Product Type

Status: ACTIVE

## UGC Patterns
- routine
- application demonstration
- texture/product showcase
- unboxing
- supported problem-solution
- lifestyle

## Interaction
Keep application physically plausible for the supplied product form. Do not invent application steps, dosage, frequency, or skin reactions.

## Visual Lock
Preserve packaging, bottle/tube/jar shape, cap, label, branding, color, liquid/cream appearance, and supplied texture references.

## Claims
Only use explicitly supported cosmetic/product claims. Never invent treatment, cure, medical, guaranteed-result, clinical, percentage-improvement, certification, or expert claims.

## QC
Check packaging identity, label consistency, application plausibility, creator identity, skin representation, and claim evidence.
