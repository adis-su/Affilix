# Rositasari — Style Reference Controller

## Purpose

Defines how Affilix uses fashion and styling references without changing Rositasari's underlying identity.

## Controls

Primary controls:

- Outfit
- Silhouette
- Color direction
- Fabric and material
- Accessories
- Footwear
- Hairstyle
- Makeup direction
- Overall fashion mood

## Reference Scope

A style reference controls styling, not identity.

It may influence:

- What Rositasari wears
- How the outfit is styled
- Accessory selection
- Hair arrangement
- Makeup intensity
- Fashion mood

It must not automatically change:

- Face identity
- Age appearance
- Body proportions
- Core creator identity

## Prompt Rule

Translate the style reference into concrete clothing and styling attributes.

Do not copy unsupported product details from a generic fashion reference.

## Allowed Variation

Style may adapt to:

- Product requirements
- Campaign brief
- Platform
- Scene context
- Season
- Location
- Brand guidelines

## QC

Check that the final styling matches the requested reference while Rositasari remains recognizable as the same creator.
