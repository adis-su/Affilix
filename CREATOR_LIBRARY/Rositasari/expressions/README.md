# Rositasari — Expression System

## Purpose

Defines how Affilix selects facial expressions for Rositasari based on scene intent.

Expressions should support the narrative rather than exist as decoration.

## Expression Categories

- Neutral
- Friendly
- Curious
- Surprised
- Delighted
- Confident
- Relieved
- Impressed
- Concerned
- Thoughtful
- Playful
- Excited

## Selection Rule

Expression should be selected from:

1. Scene objective
2. Dialogue meaning
3. Product interaction
4. Emotional beat
5. Creator persona

## Identity Rule

Expression may vary significantly while facial identity remains stable.

## QC

Check that expression:

- Matches the scene intent
- Looks natural
- Does not distort facial identity
- Supports the spoken or visual message
