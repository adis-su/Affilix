# Rositasari — Wardrobe System

## Purpose

The wardrobe system defines how Affilix selects, describes, and varies outfits for Rositasari while preserving creator identity.

## Wardrobe Layers

1. Wardrobe identity — the creator's established fashion DNA.
2. Outfit rules — constraints for selecting and combining pieces.
3. Outfit library — reusable outfit records.
4. Campaign outfit — scene-specific outfit selected for a product or brief.

## Identity Rule

Wardrobe can change between campaigns and scenes. Creator identity must remain stable.

## Selection Priority

1. Explicit campaign requirement
2. Product compatibility
3. Creator wardrobe identity
4. Platform context
5. Scene context
6. Aesthetic variation

## Required Output

Every selected outfit should be describable through:

- Top
- Bottom
- Dress/one-piece when applicable
- Outerwear
- Footwear
- Bag
- Accessories
- Hijab/headwear when applicable
- Color palette
- Materials
- Silhouette
- Styling notes

## Accuracy Rule

Do not invent branded clothing, product details, materials, or campaign claims without a source or user instruction.
